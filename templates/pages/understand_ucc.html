{% if is_gujarati %}૧. સમાન નાગરિક સંહિતા (UCC) એટલે શું?{% else %}1. What is the Uniform Civil Code?{% endif %}

{% if is_gujarati %} ભારતના બંધારણના અનુચ્છેદ ૪૪ (Article 44 of the Directive Principles of State Policy) હેઠળ રાજ્ય સમગ્ર દેશમાં નાગરિકો માટે સમાન નાગરિક સંહિતા સુરક્ષિત કરવાનો પ્રયાસ કરશે તેવી જોગવાઈ છે. UCC નો અર્થ છે કે લગ્ન, છૂટાછેડા, વારસાઈ અને ઉત્તરાધિકાર જેવા નાગરિક અને અંગત બાબતોમાં ધર્મના આધારે અલગ-અલગ વ્યક્તિગત કાયદાઓ (Personal Laws) ના બદલે તમામ નાગરિકો માટે એકસમાન કાયદાકીય માળખું લાગુ કરવું. {% else %} Under Article 44 of the Directive Principles of State Policy in the Constitution of India, the State is directed to endeavor to secure for citizens a Uniform Civil Code across the country. In practice, a Uniform Civil Code replaces fragmented religious personal laws with a unified, codified civil statutory framework governing family, marital, and succession affairs. {% endif %}

{% if is_gujarati %}૨. ગુજરાત UCC અધિનિયમ ૨૦૨૬ હેઠળ શું આવરી લેવાયું છે?{% else %}2. What Does the Gujarat UCC Act Cover?{% endif %}

{% if is_gujarati %} ગુજરાત સરકારે માર્ચ ૨૦૨૬માં વિધાનસભામાં પસાર કરેલ અને ૧ ઓક્ટોબર ૨૦૨૬ના રોજ અસાધારણ ગેઝેટમાં પ્રકાશિત થયેલ અધિનિયમ નીચેના ૪ સ્તંભો પર કેન્દ્રિત છે: {% else %} Passed by the Gujarat Legislative Assembly in March 2026 and published in the Extraordinary Gazette on 1 October 2026, the legislation codifies four cardinal pillars: {% endif %}

{% if is_gujarati %}લગ્ન અને છૂટાછેડા{% else %}Marriage & Divorce{% endif %}

{% if is_gujarati %}ફરજિયાત લગ્ન નોંધણી, લગ્નની ન્યૂનતમ વય (સ્ત્રીઓ ૨૧, પુરુષો ૨૧), અને એકપક્ષીય મૌખિક તલાક પર પ્રતિબંધ.{% else %}Compulsory registration of marriages, minimum marital age protections, and abolition of extra-judicial dissolution.{% endif %}

{% if is_gujarati %}સંપત્તિ અને વારસાઈ{% else %}Succession & Inheritance{% endif %}

{% if is_gujarati %}દીકરીઓ અને દીકરાઓને વારસામાં સમાન હક, પૂર્વજોની સંપત્તિમાં લિંગભેદ વિના સમાનતા.{% else %}Gender-equal intestate succession granting daughters and sons identical statutory inheritance shares.{% endif %}

{% if is_gujarati %}લિવ-ઇન સંબંધો{% else %}Live-in Relationships{% endif %}

{% if is_gujarati %}સહજીવનમાં રહેતા યુગલો માટે નિર્ધારિત સમયમર્યાદામાં નોંધણી અને મહિલાઓ તથા જન્મેલા બાળકો માટે ભરણપોષણ સુરક્ષા.{% else %}Statutory statement of live-in relationships to safeguard women and children born of such unions.{% endif %}

{% if is_gujarati %}વિલ અને ભરણપોષણ{% else %}Wills & Maintenance{% endif %}

{% if is_gujarati %}વસિયતનામા દ્વારા સંપત્તિના વિતરણની મુક્ત છૂટ અને વડીલો-આશ્રિતો માટે ફરજિયાત ભરણપોષણ જોગવાઈ.{% else %}Testamentary freedom for estate distribution, paired with mandatory maintenance for dependents.{% endif %}

{% if is_gujarati %}૩. કોને મુક્તિ આપવામાં આવી છે? (Exclusions){% else %}3. Statutory Exclusions & Tribal Protections{% endif %}

{% if is_gujarati %}અનુસૂચિત જનજાતિ (Scheduled Tribes) નું સંરક્ષણ:{% else %}Statutory Protection for Scheduled Tribes:{% endif %}

{% if is_gujarati %} ભારતના બંધારણના અનુચ્છેદ ૩૬૬(૨૫) હેઠળ વ્યાખ્યાયિત અનુસૂચિત જનજાતિઓના પરંપરાગત અધિકારો, રીત-રિવાજો અને રૂઢિગત પ્રથાઓને અધિનિયમની કલમ ૩ હેઠળ સંપૂર્ણ મુક્તિ આપવામાં આવી છે. {% else %} Under Section 3 of the Act, customary practices, tribal rites, and heritage protections of members of Scheduled Tribes (as defined under Article 366(25) of the Constitution) are explicitly exempt from the operational scope. {% endif %}

{% if is_gujarati %}૪. અત્યારે કાયદો કઈ સ્થિતિમાં છે?{% else %}4. What is the Exact Operational Status Today?{% endif %}

{% if is_gujarati %} મહત્વપૂર્ણ કાનૂની સ્પષ્ટતા: રાષ્ટ્રપતિ મંજૂરી મળી ગઈ છે અને કાયદો ગેઝેટમાં પ્રકાશિત થઈ ચૂક્યો છે. પરંતુ કાયદાની પ્રારંભિક કલમ મુજબ, રાજ્ય સરકાર દ્વારા અલગથી 'અમલવારી જાહેરનામું' (Commencement Notification) બહાર પાડ્યા બાદ જ નિયત તારીખથી આ કાયદો રાજ્યમાં વિધિવત અમલમાં આવશે. અત્યારે સરકાર દ્વારા સંબંધિત નિયમો (Rules) અને પોર્ટલની તૈયારી ચાલી રહી છે. {% else %} Critical Legal Fact: While Presidential Assent has been granted and the Act appears in the Extraordinary Gazette, Section 1(2) explicitly provides that the Act comes into force only on an appointed date specified by State Government Gazette notification. As of October 2026, administrative rules and digital registries are being formulated prior to the appointed commencement date. {% endif %}
